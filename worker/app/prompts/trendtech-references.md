### Element rules

**1. Brand logo (top-right)**
- ~80×80px area
- Outlier's mark (triangle/wordmark)
- Stays consistent every post = brand recall

**2. Tool icon (top-left of photo, optional)**
- Logo ของ tool ที่คลิปพูดถึง (Claude, Kling AI, ChatGPT, Gemini, etc.)
- ~120×120px square, white bg, slight shadow
- ใช้เมื่อคลิปพูดถึง tool เฉพาะ — ถ้าคลิปไม่ได้พูดถึง tool ใดเด่นๆ ให้ omit

**3. Hand-drawn arrow + caption**
- Arrow: black, marker-pen style, ลายมือเอียง ~30°-45° ชี้ไปที่คน
- Caption 1-2 บรรทัด, font ขาวเล็ก (~32-40px)
- บรรทัดที่ 2 เน้นตัวเลข/เงิน → highlight สีเหลือง `#FFD400` (text color)
- ตัวอย่าง:
  - "สร้างทุกอย่างด้วยตัวเองและ AI" / "**ทำเงิน 2.7 ล้านบาท**"
  - "สอนใช้ Claude AI Pro" / "ที่**ทำเงินได้หลักล้านบาท**"
  - "ใช้ AI สร้างระบบภายใน 20 นาที" / "**ทำเงินไปกว่า 3 แสนบาท**"

**4. Inset proof image (optional, ~50% chance)**
- Screenshot ของ proof: App Store page, dashboard, Udemy profile, Sensor Tower data
- เอียง ~3°-7° (slight rotation, ไม่เยอะ)
- Drop shadow soft
- ตำแหน่ง: มุมล่างซ้ายของ photo area, ทับ photo บางส่วน
- ขนาด ~30-35% ของ canvas width

**5. YouTube channel badge (mid-right of photo)**
- White rounded pill (border-radius: 100px)
- Avatar (round) + channel name + sub count
- Verified checkmark ถ้ามี
- ตัวอย่าง: "Ben AI / 134K subscribers"

**6. Black bottom band (35-40% of canvas)**
- Pitch black `#000000`
- Padding generous (top: 36px, sides: 56px, bottom: 32px)

**7. Headline 3 lines + subhead**
- L1, L2, L3: white text, ~58-62px Thai bold
- Subhead: ~22-26px, italic-feel (regular weight + opacity 0.75), wrapped in `- ... -`

## Decoded patterns

### Pattern frequency
- **All 13 refs use 3-line headline** + subhead (no exceptions)
- **All 13 refs have tri-color highlight** (red bg L1, yellow text L2, blue/orange bg L3)
- **All 13 refs have YouTube channel badge** (with subscriber count)
- **All 13 refs have hand-drawn arrow + caption with yellow $ figure**
- **~70% (9/13) have inset proof image** (screenshot tilted)

### Headline structural rules
1. **L1 always opens with action verb or "[noun] + dramatic claim"**
   - Action verbs ใช้บ่อย: สร้าง, เริ่ม, แชร์, ไขเคล็ดลับ, สรุป
   - Noun openers: "วัยรุ่น Gen Z", "ธุรกิจใหม่", "บริการ"
   - **Highlighted phrase = pain/dream OUTCOME** (เงินแสน, รายได้หลักล้าน, แสนน่าเบื่อ)

2. **L2 always has THE METHOD/HOW**
   - Connectors: "ด้วยการใช้", "จากการ", "โดยใช้", "วิธี"
   - **Highlighted phrase = the actual technique** (สร้าง app กว่า 35 ตัว, ใช้แค่ Claude AI Pro)

3. **L3 always has TOOL or SPECIFIC FRAMEWORK or AUDIENCE PROMISE**
   - Highlighted: framework name, tool name, ultimate promise
   - "[Software as a Service]", "[ไอเดียและ Claude Code]", "[ที่น่าจับตาที่สุดในปี 2026]"

4. **Subhead = full sentence summary**, ครอบด้วย `- ... -`
   - Functions as preview/teaser
   - 1 บรรทัดยาว ~70-90 chars

### Tone calibration
- ใช้ "เคล็ดลับ", "ไขเคล็ดลับ", "สูตรลับ" — TrendTech ใช้คำพวกนี้บ่อย → unbanned (เหมือน Earth's existing refs)
- ใช้ตัวเลขเยอะ: $ figure, time figure, count figure
- ใช้ comparison: "แค่ X แต่ Y", "มีน้อยแต่ได้มาก", "ใช้แค่ AI ทำเงินกว่า..."

### Anti-patterns (TrendTech ไม่ทำ)
- ❌ ไม่มี emoji ใน headline
- ❌ ไม่มี "..." (ellipsis)
- ❌ ไม่มี em-dash ใน Thai
- ❌ ไม่มี clickbait แบบไม่มีตัวเลข ("เปลี่ยนชีวิต", "ปลดล็อก")
- ❌ ไม่มี hashtag ในภาพ cover

## Mapping จาก source video → highlight zones

**Step 1:** อ่าน transcript → หา 3 things:
- (a) **Outcome**: เงิน/เวลา/scale (ใช้ใน L1 red highlight)
- (b) **Method**: tool/process/strategy (ใช้ใน L2 yellow text)
- (c) **Specificity**: framework name/tool name/year/promise (ใช้ใน L3 orange highlight)

**Step 2:** Compose 3 lines around those zones:
```
L1: [opening] + {{a outcome}} + [completion]
L2: [connector] + {{b method}} + [optional completion]
L3: [setup] + {{c specificity}} + [optional finisher]
```

**Step 3:** Subhead = compress thesis into 1 sentence with `- ... -` wrapping

## When to use TrendTech template vs legacy

**Use `trendtech-portrait` (DEFAULT going forward)** when:
- Topic = success story / case study / framework breakdown (ตรง TrendTech style)
- Source video has clear $ figure / time figure / scale figure
- Want strong scroll-stop on FB feed (portrait outperforms square in feed)

**Keep legacy `thumbnail-bottom`** when:
- Topic is more reflective/philosophical (no clear number)
- Want square format for IG cross-post
- Earth specifies legacy

Default rotation: 70% trendtech-portrait, 30% legacy variants for variety.
