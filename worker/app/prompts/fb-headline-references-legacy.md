## 🎯 Master Pattern (signature — 5/9 = 55% of refs)

### **Question-Promise-Credibility**

```
L1 (orange, ~76px): ใช้ [TOOL/CONCEPT] ยังไง?
L2 (white, ~76px):  ให้ [VIVID metaphor / outcome]
L3 (small, parens): ([SOURCE / INSIDER tip / สูตรโกง / ด้านมืด / คำแนะนำ])
```

### Anatomy of each line

**L1 — The Question Hook**
- Always ends with `?`
- Format: "ใช้ [X] ยังไง?" / "เอา [X] มา[verb] ยังไง?"
- [X] = tool name (Claude / Claude Code / AI agent / AI / ChatGPT) OR concept (Sales Funnel / Personal Branding)
- WHY it works: cliffhanger forces brain to want answer (Sugarman slippery slide)

**L2 — The Vivid Promise**
- Always begins with `ให้`
- Then a VIVID metaphor or specific outcome
- Best L2 patterns from refs:
  - "ให้เหมือนมี [persona]" (เหมือนมีลูกน้องเป็นร้อยคน / เหมือนมีเลขาส่วนตัว)
  - "ให้เก่งเหมือน [skilled persona]" (เหมือนนักออกแบบมือโปร)
  - "ให้เก่งแบบ [persona] [intensifier]" (เก่งแบบ Dev ระดับโลก)
  - "ให้ [outcome] ไม่ต้อง [obstacle]" (ให้หาเงินล้านได้ ไม่ต้องโชว์หน้า)

The metaphor must be **concrete and visual** — เลขาส่วนตัว, ลูกน้องร้อยคน, นักออกแบบมือโปร — NOT abstract ("ให้เก่งขึ้น" = ❌ generic)

**L3 — The Credibility Hook (always in parens, smaller font)**
- Format options observed:
  - "(สูตรโกงจาก [identifier])" — Ruri, Iman
  - "(สูตรโกงคน [pain group])" — Iman
  - "(คำแนะนำจาก [name] [credential])" — Hormozi
  - "(ด้วย [philosophy/method] ของ [name])" — Marc Lou
  - "(จาก[creator role] [credential])" — Sabrina
  - "(ด้านมืดที่ [counterintuitive insight])" — Hamza
  - "(ยุคนี้เขาวัดกันที่ X ไม่ใช่ Y)" — Riley *(insider tip preview)*
  - "(จากประสบการใช้งานจริง [specific time/scale])" — Jono

L3 is NOT just credit — it's a **second hook** that adds curiosity, insider feel, or counterintuitive framing.

## 🔄 Secondary Pattern (Listicle — 3/9 refs)

```
L1: [N] [วิธี/เคล็ดลับ/บทเรียน/ขั้นตอน] [topic]
L2: ที่ [outcome with multiplier/specifics]   หรือ   ไม่ [pain] ไม่ [pain]
L3: ([source / credential / curiosity tease])
```

Examples:
- "5 วิธีหาเงินด้วย AI ในปี 2026 / ไม่ต้องโชว์หน้า ไม่มีทุนก็เริ่มได้"
- "27 เคล็ดลับ Claude Code / ที่รู้แล้วจะทำให้งานเสร็จไวขึ้น 10x"
- "3 บทเรียนจาก Web Designer / ที่ทำ Digital Product มา 10 ปี"

Use when: source is a list / framework / step-by-step. Specific number wins.

## ✅ Words/phrases that ARE allowed (ในที่เคยห้าม)

จากการดู refs จริง คำเหล่านี้ทำงาน — **ไม่ใช่ red flag**:
- ✅ "เคล็ดลับ" (Jono "27 เคล็ดลับ")
- ✅ "สูตรโกง" (Ruri, Iman)
- ✅ "ด้านมืด" (Hamza)
- ✅ "ระดับโลก" (Riley)
- ✅ Vague intensifier "เก่งแบบ X" (Riley)

**ที่ยังห้ามอยู่จริงๆ:**
- ❌ "เปลี่ยนชีวิต" — overpromise, not in any ref
- ❌ "ปลดล็อก" — AI marketing-speak, not in any ref
- ❌ "ในยุคที่..." — AI Thai pattern (ในข้อความ body, ส่วน L3 "ยุคนี้เขาวัดกันที่..." ของ Riley OK เพราะใช้แบบ insider observation)

## 🧪 Stress test before committing a headline

After drafting, ask 3 questions:

1. **L1 ends with "?" or starts with a number?** ถ้าไม่ใช่ทั้งคู่ → reconsider (signature pattern หรือ listicle)
2. **L2 contains a VIVID concrete picture?** ลูกน้องร้อยคน / เลขาส่วนตัว / นักออกแบบมือโปร / 10x faster — not "ดีขึ้น" / "เก่งขึ้น"
3. **L3 in parens with insider feel / source authority / curious tease?** Not just "(จาก X)"

ถ้าไม่ผ่านทั้ง 3 → drop ไป pattern อื่น

## ⚠️ Anti-pattern: my recent failures

**Hormozi cover (failed):** "Hormozi ทำ $250M / ด้วยกฎเลือกธุรกิจ 5 ข้อ / Solopreneur ใช้ได้ทันที"

- ❌ L2 "ด้วยกฎ X ข้อ" generic ไม่ vivid
