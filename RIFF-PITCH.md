---

## 1. Problem

**Creator economy ไทย/SEA โต 30%+ YoY** — แต่ creator คนเดียวที่อยาก scale เจอ wall เดียวกัน:

- **บริษัทใหญ่ + agency** → ลูกค้ารายละ 30,000-100,000 บาท/เดือน เพดานราคา
- **DIY ด้วย ChatGPT + Canva + Notion** → ใช้ stack 5-6 tool, ทำได้ 1 เดือนแล้ว burnout
- **Generic AI** → output เหมือนกันทุกคน คนอ่านแยกออกใน 2 บรรทัด

**Hidden pain (ที่ไม่มีใครพูด):**
ปัญหาไม่ใช่ "ทำ 1 post ช้า" — ทุก tool focus ตรงนี้
ปัญหาคือ **"ลงต่อเนื่อง 90 วันยาก"** เพราะไม่รู้จะลงเรื่องอะไรในแต่ละวัน

= Discovery is the unsolved problem in the creator stack

---

## 2. Solution

**Riff = Daily content habit engine ที่ใช้ AI ทำ 4 step ของ content team ให้ creator คนเดียว:**

```
1. Research      → AI scan top creators in niche → outliers ทุกวัน
2. Organize      → Idea Library + boards
3. Decode        → AI แกะ structure ของคลิป viral
4. Recreate      → AI เขียนใหม่ใน voice ของ creator (FB/IG/Reels/YT)
```

**Differentiation vs ChatGPT + Canva combo:**
- ChatGPT ไม่ scan YouTube ให้ — ต้อง user หาเอง
- Canva ไม่บอก "post ไหนดังจริง" — ต้อง user เดาเอง
- Riff = single workflow ที่ถ้าเปิดทุกเช้า user ลง 1 post/วันได้โดยไม่คิด

## 3. Why Now

**3 trends collide:**

1. **AI text gen ดีพอจน rewrite ได้แม่น 90%+ ของ original voice** (Claude Sonnet 4.6, GPT-4o)
   2 ปีที่แล้ว AI = generic / 6 เดือนที่แล้ว = inconsistent / ตอนนี้ = production-ready

2. **Creator economy เปลี่ยน "ใหญ่ไม่ใช่กำไร"**
   ทีมเล็ก profit-share หลักล้าน/เดือน เป็น norm มากขึ้น (Justin Welsh, Codie Sanchez)
   = ตลาดของ **"creator ที่อยากเป็น 1-person CEO"** กำลังโต

3. **Eden.so (US) แสดงให้เห็นแล้วว่า model นี้ใช้ได้**
   Pre-seed → Series A ใน 14 เดือน · ARR 7-figure
   ตลาดได้ proof แล้ว — Riff = Eden + Thai/SEA localization
